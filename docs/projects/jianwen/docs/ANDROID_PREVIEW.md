# Android 公开预览包

文件：[jianwen-1.0.1-public-preview.apk](https://github.com/UzimakeNarutoszx/personal-website-oss/releases/download/public-editions-2026-11-01/jianwen-1.0.1-public-preview.apk)，作为 GitHub Release 附件分发，不进入源码历史

这是原 Android 1.0.1 包经过脱敏重打包的独立公开预览产物。保留原有 uni-app / DCloud Android 运行时及客户端编译代码，没有声称通过本仓库源码完整重现原生构建。

## 处理范围

- 删除应用资源清单中的完整分发配置（包括签名配置）、开发者字段和广告标识字段。
- 删除原渠道账号元数据，移除原服务器地址和明文网络例外。
- 默认 API 改为不可用示例域名，避免预览包连接原部署。
- 原宣传视频及封面全部替换为公开版合成数据截图和无声导览；原视频和音轨均未保留。
- 去除原始签名，使用只含项目通用名称的新 RSA 3072 位证书签名。私钥和签名密码均不在仓库内。

## 已执行的检查

- 全归档字符串提取覆盖 DEX、原生动态库、资源和应用文件；检查已知身份、原部署地址和私有配置值。
- 对应用清单确认无分发签名字段，对证书确认仅有 `CN=Jianwen Public Preview,O=Jianwen,C=CN`。
- 385 张原包位图通过接触表检查，未见真人照片；公开预览宣传图与视频替换为已审核的真实界面演示。
- 执行 `zipalign` 和 `apksigner verify`，签名验证通过。密钥扫描仅剩第三方编辑器库的键盘快捷键常量误报，人工确认并非凭据。

## 使用限制

未在真机或模拟器安装运行，不能据此保证全部运行时行为。示例后端不可用，在线功能默认不可用。原包名未变但签名已变，不能覆盖原版本；卸载原版可能丢失本机数据。正式发布应使用自有环境和签名，从源项目重新构建并完成设备验证。

第三方 Android 运行时及 SDK 不因本项目 MIT 许可证而改变其原有条款。
