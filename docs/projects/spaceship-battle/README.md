# 飞船大战

## 功能

飞船移动、子弹、敌机和碰撞判定的早期游戏实验。

## 技术栈

Python、Arcade、Pyglet。依赖版本以现有清单和上游兼容要求为准，早期代码可能需要历史版本。

## 目录

飞船大战.py 主程序。

## 启动

在本仓库目录执行；Python 示例需先激活自行创建的虚拟环境。

```sh
python3 -m venv .venv
# 激活虚拟环境后
python3 -m pip install arcade pyglet
python3 飞船大战.py
```
