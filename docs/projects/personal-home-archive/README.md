# 个人主页工具归档

## 功能

从历史个人主页中提取图片通道交换工具，移除个人介绍、导航、相册、音乐与留言模块。

## 技术栈

Python、Streamlit、Pillow。依赖版本以现有清单和上游兼容要求为准，早期代码可能需要历史版本。

## 目录

my_home.py 图片处理演示。

## 启动

在本仓库目录执行；Python 示例需先激活自行创建的虚拟环境。

```sh
python3 -m venv .venv
# 激活虚拟环境后
python3 -m pip install streamlit pillow
streamlit run my_home.py
```
