# Go For It

## 功能

地图、角色移动、碰撞和游戏流程实验。

## 技术栈

Python、Arcade、Tiled TMX。依赖版本以现有清单和上游兼容要求为准，早期代码可能需要历史版本。

## 目录

main.py 游戏逻辑；other_files/ TMX 地图。

## 启动

在本仓库目录执行；Python 示例需先激活自行创建的虚拟环境。

```sh
python3 -m venv .venv
# 激活虚拟环境后
python3 -m pip install arcade
python3 main.py
```
