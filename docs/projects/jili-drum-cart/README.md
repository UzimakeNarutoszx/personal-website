# 记里鼓车

## 功能

记里鼓车的交互展示与滚动、运动逻辑。

## 技术栈

Python、Arcade、Pillow。依赖版本以现有清单和上游兼容要求为准，早期代码可能需要历史版本。

## 目录

main.py 交互程序。

## 启动

在本仓库目录执行；Python 示例需先激活自行创建的虚拟环境。

```sh
python3 -m venv .venv
# 激活虚拟环境后
python3 -m pip install arcade pillow
python3 main.py
```
