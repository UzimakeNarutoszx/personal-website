# 平台动作游戏源码归档

## 功能

桌面版、前传、节庆版及网页版本的平台移动、碰撞和技能逻辑。

## 技术栈

Python、Arcade、JavaScript、HTML、Tiled TMX。依赖版本以现有清单和上游兼容要求为准，早期代码可能需要历史版本。

## 目录

desktop/ 主版本；prequel/ 前传；new-year/ 节庆版；web/ 网页版。

## 启动

在本仓库目录执行；Python 示例需先激活自行创建的虚拟环境。

```sh
python3 -m venv .venv
# 激活虚拟环境后安装与历史代码兼容的 arcade
python3 -m pip install arcade
cd web
python3 -m http.server 8080
```
