# 机器人竞赛程序归档

## 功能

从竞赛及培训项目中提取积木控制逻辑，包含 PID 和遥控程序。

## 技术栈

Scratch 3 项目 JSON、机器人扩展积木。依赖版本以现有清单和上游兼容要求为准，早期代码可能需要历史版本。

## 目录

scratch-code/ 去媒体、注释和运行值的积木 JSON。

## 启动

在本仓库目录执行；Python 示例需先激活自行创建的虚拟环境。

```sh
# 打开 scratch-code/ 下的 *.blocks.json 查看积木逻辑
# 需在兼容机器人扩展的编辑器中手动重建，不能直接当作 sb3 导入
```
